# Data Directory

This directory contains the cleaned and processed datasets used by the **Online Retail Customer Value Analytics** project.

## Original data source

The project uses the **Online Retail II** dataset from the UCI Machine Learning Repository:

- Dataset page: https://archive.ics.uci.edu/dataset/502/online+retail+ii
- DOI: https://doi.org/10.24432/C5CG6D
- Citation: D. Chen, *Online Retail II*, UCI Machine Learning Repository, 2012.
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)

The source dataset contains approximately 1.07 million transaction records from a UK-based non-store retailer between December 2009 and December 2011. It includes invoice, product, quantity, price, customer and country information.

```text
│   └── online_retail_cleaned.csv
└── processed/
    ├── customer_clv_model.csv

    └── customer_clv_dashboard.csv
```

### `cleaned/`

Contains transaction-level data produced by `01_data_audit_and_cleaning.ipynb` after:

- combining both source worksheets;
- removing duplicate records;
- identifying cancellations and returns;
- checking missing customer identifiers;
- validating quantities and unit prices; and
- creating valid purchase and revenue fields.

`online_retail_cleaned.csv` is optional in the public repository because it may be too large for ordinary GitHub storage. It can be regenerated by running the data-audit notebook with the original UCI Excel file.

### `processed/customer_clv_model.csv`

Customer-level analytical dataset used for descriptive analysis, statistical inference and model development. Each row represents one identified customer. It includes historical behaviour features such as:

- recency;
- purchase frequency;
- historical monetary value;
- average order value;
- total quantity purchased;
- product diversity;
- customer location; and
- future repeat-purchase and revenue outcomes.

### `processed/customer_clv_predictions.csv`

Contains customer-level model outputs, including estimated repeat-purchase probability, conditional future revenue and predicted customer value.

### `processed/customer_clv_dashboard.csv`

Presentation-ready dataset used by the Streamlit dashboard. It combines customer identifiers, model predictions, value segments and recommended business actions.

## Observation and prediction periods

- **Observation period:** 1 December 2009 to 30 November 2010
- **Future evaluation period:** 1 December 2010 to 9 December 2011

Historical behaviour is calculated only from the observation period. Repeat-purchase and future-revenue outcomes are calculated from the later period to avoid using future information as model input.

## Important data notes

- Revenue is calculated as `Quantity × UnitPrice`.
- Cancelled invoices, returns, invalid prices and unidentified customers are treated explicitly during cleaning.
- Customer identifiers should be treated as identifiers, not numerical predictors.
- Monetary variables are reported in pounds sterling (£).
- The predicted value is a fixed-horizon gross-revenue estimate, not a complete accounting measure of lifetime profit.
- The processed datasets are intended for academic analysis and should not be interpreted as current commercial customer records.

## Reproducing the data

1. Download `online_retail_II.xlsx` from the UCI dataset page.
2. Place the source file in a local raw-data directory, for example `data/raw/`.
3. Run `notebooks/01_data_audit_and_cleaning.ipynb`.
4. Run the remaining notebooks in numerical order.
5. Confirm that the processed CSV files are available before starting the dashboard.

## Git and privacy guidance

Do not commit temporary files, notebook checkpoints or local environment files. If the original or cleaned transaction files exceed GitHub's size limit, exclude them with `.gitignore` and provide the UCI download and reproduction instructions instead. The customer IDs in this public academic dataset are anonymised, but they should still be handled as identifiers rather than descriptive personal information.
